# Pokémon Collector

Petit jeu familial de collection de cartes Pokémon (500 cartes en allemand, extensions 2020 → 2025).

- Ouvrir `index.html` dans un navigateur, ou jouer en ligne via GitHub Pages.
- La partie est enregistrée dans le navigateur de chaque appareil : utiliser **💾 Exporter / 📂 Importer** pour passer d'un appareil à l'autre.

Projet de fan, non commercial. Pokémon et les images des cartes appartiennent à Nintendo / Creatures / GAME FREAK / The Pokémon Company. Données et images des cartes : [TCGdex](https://tcgdex.dev). Illustrations : [PokéAPI](https://pokeapi.co).
